# Zemoco Limited Website

Static website for Zemoco Limited — last-mile courier and fleet services across Greater London.

## Live site

After GitHub Pages is enabled:

https://daniyal258uetian.github.io/zemoco-website/

## Local development

```bash
python server.py
```

Then open http://127.0.0.1:5500/

Or double-click `start-server.bat` on Windows.
